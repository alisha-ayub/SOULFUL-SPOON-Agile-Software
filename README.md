# SOULFUL-SPOON-Agile-Software
Soulful Spoon — A full-stack recipe-sharing web app built with SvelteKit, Node.js, Express.js, and SQLite3. Includes JWT + Google OAuth authentication, recipe filtering, AI chatbot (Botpress), article publishing with TinyMCE, like/comment system, and a user dashboard with accessibility settings. Developed using Agile with Git version control.
